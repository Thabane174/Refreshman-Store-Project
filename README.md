# Refreshman-Store-Project
The Fast-Food Store Management System is a desktop application developed using 
C# Windows Forms. The application allows users to browse food items, view product 
details, select quantities, add items to a cart, and view an order summary. 
This project was created to practice Windows Forms development, event handling, 
object-oriented programming principles, and user interface design.

## Menu Display
- Displays multiple food items.     
- Includes images, names, and prices.    
- Easy-to-use visual interface.

## Food Details
- Shows:   
o Item name  
o Description  
o Category  
o Price  

## Quantity Selection: 
- Users can choose the number of items they want. 
Add To Cart: 
- Adds selected items to the order. 
- Updates the order summary. 

## Order Summary: 
- Displays:  
o Order number  
o Total cost   
o Discount information  

## Discount System 
-Customers receive a 10% discount when purchasing 5 or more food items. 

## Clear Order 
- Removes current order information.  
-Resets the shopping cart.
